# Калькулятор каркасного дома

Локальное Windows-приложение для предварительного расчёта стоимости строительства каркасного дома. Тёмный интерфейс на HTML/CSS/JS, отрисовывается через Microsoft Edge WebView2. Работает офлайн; актуальный прайс подтягивается кнопкой «Обновить данные» с Яндекс.Диска.

![скриншоn главной страницы](#) *(images/Вид%20созданного%20Калькулятора%20.png)*

## Возможности
 
- **Смета из 16 разделов** (145 позиций справочника): карточки с переключателями, типом цены (мин/база/макс), ручной правкой цены и количества
- **Автоподстановка количеств** из площади и этажности: сваи — по шагу 2,5 м по периметру, утепление — по объёму, кровля — с запасом 10–15 % и т.д.; ручные значения не перезаписываются
- **Три уровня цен** по каждой позиции + мгновенный итог и цена за м²
- **«Показать итог»** — сводка по разделам, накладные/резерв, рыночная вилка по контрольным бюджетам
- **«Обновить данные»** — скачивание прайса с Яндекс.Диска с подсветкой изменившихся позиций
- **Экспорт** — Excel (смета + прайс), CSV, печать в PDF
- Тёмная тема, анимации, тосты; данные хранятся локально (localStorage WebView2)

## Архитектура

| Компонент | Технология | Назначение |
|---|---|---|
| `www/` | HTML/CSS/JS (vanilla, SheetJS) | Интерфейс и вся логика расчёта |
| `app/CalcHost.cs` | C# WinForms + WebView2 | Оконная оболочка, виртуальный хост `app.karkas-dom.local`, прокси `/api/yandex` |
| `installer/Installer.cs` | C# WinForms | Установщик в `%LOCALAPPDATA%\KarkasDomCalculator` + ярлыки + запись «Установка и удаление программ» |

### Синхронизация с Яндекс.Диском

Файл прайса публикуется ссылкой вида `https://disk.yandex.ru/i/<id>`. Особенность: файлы, загруженные через новый конвейер «Яндекс Документов», отдают пустую ссылку в cloud-api. Оболочка решает это цепочкой:

1. `GET <ссылка>?download=1` → редирект в просмотрщик `docs.yandex.ru/view/d/<token>`
2. Из HTML просмотрщика извлекаются WOPI-идентификатор файла, `access_token` и `access_token_ttl`
3. `GET https://office-online.disk.yandex.net/v1/disk/wopi/files/<id>/contents?access_token=...` — байты XLSX

Запрос выполняется в фоновом потоке, ответ назначается через `BeginInvoke` на UI-потоке (объекты WebView2 привязаны к нему), затем `deferral.Complete()`.

Ссылка на таблицу задаётся константой `YandexPublicUrl` в `app/CalcHost.cs`.

## Сборка

Нужен только Windows с .NET Framework 4.x (csc входит в состав системы) и установленный WebView2 Runtime. Visual Studio не требуется.

```powershell
cd "Исходный код для GitHub"
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `build/out/УстановитьКалькуляторКаркасногоДома.exe` (установщик, всё встроено) и `build/out/app/` (портативная версия).

Зависимости (DLL WebView2 net462 + SheetJS) лежат в `deps/` и `www/vendor/` — скачивать ничего не нужно.

## Формат таблицы прайса

Excel/CSV с колонками:

```
ID | Раздел | Подраздел | Наименование позиции | Тип позиции |
Единица измерения | Минимальная цена | Базовая цена | Максимальная цена |
Статус | Источник | Комментарий
```

Обязательны: наименование и хотя бы одна колонка цены. Позиции сопоставляются по ID или названию.
